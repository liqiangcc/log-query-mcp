# Research fixtures

These small deterministic logs support the R-01/R-02 MCP protocol POC.

They intentionally include:

- English and Chinese-capable UTF-8 files.
- `traceId`, `orderId`, an exception name and an error status.
- A multi-line stack trace.
- Two services sharing one trace ID.

Large-file, invalid-UTF-8, rotation, symlink and special-file fixtures will be generated by scripts in later research work packages rather than committed as large or unsafe repository objects.
