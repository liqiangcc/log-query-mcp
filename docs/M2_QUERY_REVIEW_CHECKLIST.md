# M2 Query Orchestration 评审清单

## 请求与来源

- [x] 来源列表非空、唯一且受服务端上限约束。
- [x] 关键字符合 v1 字面量搜索契约。
- [x] `max_results` 受服务端限制。
- [x] 查询使用服务端 timeout 与调用方 deadline 中较早者。
- [x] 查询开始时刷新显式文件和目录发现快照。
- [x] 多来源共同执行页面文件数量上限。

## 文件与扫描

- [x] 每次扫描重新验证文件身份。
- [x] 只扫描查询开始时的文件快照大小。
- [x] 非零续扫位置验证行边界。
- [x] 页面累计扫描字节和行数。
- [x] 半行停止不会被当成安全续扫位置。
- [x] 取消和 deadline 传播到 ScanExecutor。

## 时间

- [x] RFC 3339 token 解析。
- [x] 自定义固定前缀和来源 UTC 偏移。
- [x] `[start_time, end_time)`。
- [x] 范围外有效时间被排除。
- [x] 无时间和畸形时间保守返回。
- [x] 时间解析读取受控行前缀，不依赖展示预览。

## 排序和内存

- [x] 有时间结果按绝对时间升序。
- [x] 无时间结果置后。
- [x] 相同时间按来源、文件、行号、偏移稳定排序。
- [x] 固定容量最大堆保留全局最早结果。
- [x] 匹配总数不会导致结果内存无界增长。
- [x] 最终页面内容预算再次执行。
