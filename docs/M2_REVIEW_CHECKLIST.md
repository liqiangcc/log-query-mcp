# M2 扫描器与执行器评审清单

## 扫描器

- [x] 只依赖 `Read`，不接受路径。
- [x] 固定读取缓冲区和有限行预览。
- [x] 字面量匹配跨缓冲区但不跨行。
- [x] 支持 UTF-8 中文和 ASCII 大小写折叠。
- [x] 非法 UTF-8 和 CRLF 不导致失败。
- [x] 返回行号、行首偏移、匹配偏移和行长度。
- [x] 扫描字节、结果、内容和缓冲区硬上限。
- [x] 取消和 deadline 在扫描循环中定期检查。

## 执行器

- [x] 同步扫描通过 `spawn_blocking` 隔离。
- [x] Semaphore 限制全局并发。
- [x] 排队阶段观察取消和 deadline。
- [x] 运行中取消能够协作退出。
- [x] Future 中止会取消底层令牌。
- [x] 许可在同步任务真正结束后释放。

## 自动验证

- [x] Contracts CI 通过。
- [x] Rustfmt 通过。
- [x] Clippy `-D warnings` 通过。
- [x] Rust 单元与集成测试通过。
