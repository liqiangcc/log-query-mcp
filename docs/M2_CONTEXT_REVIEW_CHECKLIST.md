# M2 Context Reader 评审清单

## match_ref 边界

- [x] 客户端只提交不透明 `match_ref`。
- [x] 服务端从 `MatchReferenceStore` 解析内部定位信息。
- [x] 来源 ID、相对路径和文件身份重新校验。
- [x] 路径仍必须属于来源显式文件或目录规则。
- [x] device / inode 变化后拒绝读取。
- [x] 文件截断到搜索快照或匹配结束位置之前时拒绝读取。
- [x] 原关键字在保存偏移变化时拒绝读取。

## 上下文读取

- [x] 前置行通过有限反向字节窗口读取。
- [x] 匹配行从保存的行起点重新读取。
- [x] 后置行按顺序读取。
- [x] 单侧行数受服务端配置限制。
- [x] 单行预览受限。
- [x] 返回内容总字节数受限。
- [x] 每个方向扫描字节受限。
- [x] 超长匹配行预览保证关键字可见。
- [x] CRLF 和非法 UTF-8 已覆盖。

## 并发与中断

- [x] 上下文 I/O 在 `spawn_blocking` 中执行。
- [x] 独立 Semaphore 限制并发上下文任务。
- [x] 排队阶段观察取消和 deadline。
- [x] 读取阶段协作检查取消和 deadline。
- [x] async Future 被丢弃后取消阻塞任务。

## 服务集成

- [x] `StatefulContextService` 共享查询服务的 Registry 和 match_ref Store。
- [x] 搜索结果可直接用于上下文读取。
- [x] 文件替换后上下文失败。
- [x] 预取消请求失败。
