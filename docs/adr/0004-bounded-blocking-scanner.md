# ADR-0004：使用有界同步扫描器和受限阻塞执行器

- 状态：Accepted
- 日期：2026-06-20

## 决策

- 扫描器基于标准 `Read` 接口同步、流式读取。
- 使用固定缓冲区，不加载完整文件。
- 使用 `spawn_blocking` 与 Tokio 控制面隔离。
- 使用独立 Semaphore 限制同时扫描任务数。
- 扫描循环检查 CancellationToken、deadline 和资源配额。
- 不调用外部 `grep`、`rg` 或 Shell。

## 原因

该模型使文件 I/O、匹配算法和 MCP 协议解耦，并能对超长行、非法 UTF-8、扫描字节、结果数和响应内容实施硬限制。

## 后果

- 普通文件系统调用不能被安全强制终止，只能协作取消。
- 没有索引时，查询成本与扫描数据量相关。
- `newest_first` 需要独立的反向扫描方案，v1 后置。
