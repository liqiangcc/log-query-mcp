# ADR-0002：远程服务使用 Streamable HTTP

- 状态：Accepted
- 日期：2026-06-20

## 决策

- 正式远程传输使用 MCP Streamable HTTP。
- stdio 仅用于本机调试和协议烟测。
- 默认监听回环地址，内网监听必须显式配置。

## 原因

服务部署在远程日志服务器，本地 AI 需要跨主机调用。Streamable HTTP 已在预研中验证协议协商、工具发现、SSE、会话 ID、分页、上下文和会话删除。

## 后果

- 需要处理 HTTP 会话、断连和取消传播。
- v1 不内置认证和 TLS，依赖受控内网。
- 未来暴露到非受控网络时必须重新设计身份认证、来源授权和 TLS。
